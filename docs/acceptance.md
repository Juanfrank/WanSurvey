# MVP acceptance

The acceptance list of spec §13, with the automated tests that prove each item. All of them run in CI on every push.

| Criterion                                                                                                                                                             | Tests                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| One questionnaire with a roster, 10+ skips, hard and soft checks and piped text is fielded in all four modes, and the merged export has identical variables and codes | Household questionnaire (`packages/fixtures/src/household.ts`) run in every mode: `e2e/preview.spec.ts` (CATI by keyboard, CAWI on a phone, PAPI print), `e2e/capi.spec.ts`, `e2e/cawi.spec.ts`, `e2e/papi.spec.ts`; merged export across CAPI, CATI, CAWI and PAPI with the same columns and labels: `apps/api/test/analytics.test.ts` (“merges all four modes…”); simulated household interviews in all modes: `apps/api/test/simulate.test.ts` |
| Changing an early answer that alters the path clears the right items, notifies the interviewer and is recorded in history                                             | `packages/logic/test/engine.test.ts`; `packages/renderer/test/runner.test.tsx` (“announces answers cleared…”); `e2e/preview.spec.ts` (“changing an earlier answer clears later ones…”); `apps/api/test/interviews.test.ts` (history)                                                                                                                                                                                                              |
| Killing the browser mid-interview loses zero answers in every mode; a CAPI tablet completes 20 interviews offline and syncs them all                                  | `e2e/interview.spec.ts` (reload and going offline), `e2e/cawi.spec.ts` (respondent resumes after a reload), `e2e/capi.spec.ts` (offline after a reload); `apps/api/test/capi.test.ts` (“twenty interviews done offline all arrive…”)                                                                                                                                                                                                              |
| CATI interviewer can work an entire shift by keyboard only, including callbacks                                                                                       | `e2e/cati.spec.ts` (“a telephone shift by keyboard: callback, callback served first, answered interview”)                                                                                                                                                                                                                                                                                                                                         |
| 1,000 CAWI invitations are sent, tracked, reminded and completed, with bounces handled                                                                                | `apps/api/test/cawi.test.ts` (“sends a wave to 1,000 cases with reminders…”, “bounces suppress the address…”); `e2e/cawi.spec.ts`                                                                                                                                                                                                                                                                                                                 |
| Supervisor sees completes and per-interviewer metrics update within 5 s                                                                                               | `apps/api/test/analytics.test.ts` (“…updates it within 5 seconds of a submission”, through the stats job and Redis-style bus); `e2e/analytics.spec.ts` (the dashboard updates live, with the worker and Redis)                                                                                                                                                                                                                                    |
| Reviewer returns an interview with a comment, the interviewer fixes it, and the change history shows both                                                             | `apps/api/test/review.test.ts`; `e2e/review.spec.ts`                                                                                                                                                                                                                                                                                                                                                                                              |
| Each role is denied access to endpoints outside its permissions                                                                                                       | `apps/api/test/rbac.test.ts` (every endpoint × every role) and `apps/api/test/rls.test.ts` (tenant isolation)                                                                                                                                                                                                                                                                                                                                     |
| Export to CSV, XLSX and SPSS opens correctly with labels                                                                                                              | SPSS and Stata read back with pyreadstat and pandas: `packages/exporters/test/writers.test.ts`; Excel read back with labels and codebook sheets: `apps/api/test/analytics.test.ts`; CSV header and rows: `e2e/analytics.spec.ts`                                                                                                                                                                                                                  |

Performance targets (spec §12) and how they are covered:

| --------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |

| 300 concurrent interviewers; 50 CAWI completes per second | `load/sync-300.js`, `load/cawi-burst.js` (k6, on staging)                                                                     |
| Dashboard within 5 s of a submit                          | As above                                                                                                                      |
